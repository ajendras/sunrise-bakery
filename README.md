# 🥐 Sunrise Bakery

Family bakery in Jaipur’s C-Scheme baking fresh bread, eggless cakes & cookies daily. Order custom cakes on WhatsApp.

**Live site:** https://ajendras.github.io/sunrise-bakery/

## What's on the site

- `/` — Sunrise Bakery
- `/menu/` — Menu & Prices
- `/cakes/` — Custom Cakes
- `/about/` — Our Story
- `/faq/` — FAQ
- `/contact/` — Contact & Visit
- `/404/` — Page Not Found

## Features

- 🌾 **Fresh Daily** — Bread, cookies and cakes baked fresh every single morning in our Jaipur kitchen.
- 🥚 **100% Eggless** — All cakes and many cookies are completely egg-free to suit dietary needs.
- 🎂 **Custom Cakes** — Personalised designs and flavours for birthdays, anniversaries and events.
- 📍 **C-Scheme Location** — Easy to find in central Jaipur with ample parking and pickup options.
- 💬 **WhatsApp Orders** — Instant custom-cake quotes and ordering via our dedicated number.
- 📋 **Clear Pricing** — Transparent menu with weights and prices so you know exactly what you pay.
- 🕒 **Long Hours** — Open daily 8:00–21:00 so you can pick up fresh bread on your way home.

## Edit and run

Built with **Plain HTML, CSS & JavaScript (no build, fastest)**.

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Every push to `main` publishes the site automatically with GitHub Pages.
